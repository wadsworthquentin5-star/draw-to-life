DRAW → WATCH → UNDERSTAND

Physics, on a blank page.

  1. Sketch one moving object and its surroundings.
  2. Label x₀, v₀, a, t with values and units. Add v = ? or x = ?.
  3. Use the dotted selection tool to box the object that moves. Recognition can suggest this box too.
  4. Tap Bring to life, review the values, and watch.
  5. Open Work it out. Write a step and pause for the Check bubble.

Handwriting recognition needs a Gemini API key on the server. The demo, typed labels, manual values, and equation checking work offline.

Only the sketch or the new handwritten step is sent for recognition when you request it. Nothing is sent while you draw.

This prototype checks arithmetic and equations for one constant-acceleration problem. It does not grade prose proofs or arbitrary physics. Pages stay in memory; a refresh clears them.
